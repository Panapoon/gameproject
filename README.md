# 🎵 Beep Boop — Rhythm Game

เกมแนว **Rhythm Game** ที่พัฒนาด้วยภาษา **Python** และไลบรารี **Pygame**

ผู้เล่นจะต้องกดปุ่มให้ตรงกับจังหวะของโน้ตเพลงที่ปรากฏบนหน้าจอ โดยระบบจะตรวจสอบความแม่นยำในการกดและคำนวณคะแนน รวมถึง Combo และผลการเล่นในแต่ละเพลง

---

## 🎮 เกี่ยวกับโปรเจกต์

**Beep Boop** เป็นเกม Rhythm Game 2D ที่เน้นการกดปุ่มให้ตรงกับจังหวะของเพลง

ภายในเกม ผู้เล่นสามารถเลือกเพลงก่อนเริ่มเล่น จากนั้นโน้ตจะปรากฏตามจังหวะของเพลง ผู้เล่นต้องกดปุ่มให้ถูกต้องและตรงเวลาเพื่อทำคะแนนให้ได้สูงที่สุด

หลังจากเล่นเพลงจบ ระบบจะแสดงผลคะแนนและสถิติการเล่นในหน้า Summary

---

## ✨ ฟีเจอร์ของเกม

### 🎵 เลือกเพลง

* สามารถเลือกเพลงที่ต้องการเล่น
* แสดงรายการเพลงภายในเกม
* สามารถกลับไปยังหน้าเมนูหลักได้

### 🎮 ระบบ Gameplay

* โน้ตปรากฏตามจังหวะของเพลง
* รับ Input จาก Keyboard
* ตรวจสอบความแม่นยำของการกด
* ระบบคำนวณคะแนน
* ระบบ Combo
* ระบบคำนวณ Accuracy
* เล่นเพลงพร้อมกับ Gameplay

### 🏆 ระบบตัดสินคะแนน

### 📊 หน้า Summary

* จำนวน PERFECT

* จำนวน BAD
* จำนวน MISS
* Rank

มีหน้า Options สำหรับจัดการการตั้งค่าต่าง ๆ ของเกม

* รูปภาพและ Font สำหรับตกแต่งเกม
* ระบบเสียงและเพลงประกอบ

## 📄 รายละเอียดไฟล์หลัก

* Options

* Keyboard Input

* การคำนวณคะแนน
* การคำนวณ Combo

## 🏆 ระบบคะแนน

ระบบจะตรวจสอบระยะห่างระหว่างเวลาที่โน้ตควรถูกกดกับเวลาที่ผู้เล่นกดจริง

ตัวอย่างผลลัพธ์:

| ผลการกด     | ความแม่นยำ            |
| ----------- | --------------------- |
| **PERFECT** | ตรงจังหวะมากที่สุด    |
| **GOOD**    | ใกล้เคียงจังหวะ       |
| **BAD**     | คลาดเคลื่อนจากจังหวะ  |
| **MISS**    | ไม่สามารถกดโน้ตได้ทัน |

ผลการกดทั้งหมดจะถูกนำไปใช้ในการคำนวณคะแนนและ Accuracy ของผู้เล่น
